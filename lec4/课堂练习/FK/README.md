# Week 4：预设姿态与动作（1.1）

沿用 lec3 的六只 SCS215 和编号，实现关节空间预设姿态与动作播放。最新范围已与 lec3 同步：ID3 为 **319～903**，ID5 重装后为 **400～976**，ID5 的模型 0° 对应 **688**，方向不变。参数简表见项目 `settings/servo_info.json`。

## 运行

在本目录打开 PowerShell，运行：

```powershell
& D:\miniconda\envs\lerobot\python.exe .\control_fk.py
```

自动识别原转接板，也可以加 `--port COM9`。运行前关闭上次的串口控制窗口。
启动只读取六个当前位置，滑条由实测值初始化，不先复位；拖动滑条或点击“设置”才控制对应关节。

没有连接机械臂时可以加 `--demo` 体验完整界面。模拟模式不打开串口，录制与时间设置仅保存在内存，不污染实际记录。

## 先记录，再演示

1. 用六个滑条调整到课件图中的**立正**姿态。右侧选择 `stand`，等机械臂停稳，点“记录当前实测姿态”。记录六个反馈位置，而非未到达的滑条目标。
2. 同样记录 `lift`（抬起）、`left`（向左）、`right`（向右）。左右姿态应围绕抬起姿态适度变化；每次记录的是整条手臂的六个位置。无需重做 0/1 端点校准。
3. 点击窗口非输入框区域，按 **1** 去立正；按 **2** 挥手。挥手默认：抬起 → 向左 → 向右 → 向左 → 抬起。每次都从实测当前位置开始。
4. 右侧可修改动作每段的姿态、运动时间和到位后的停留时间，点击“保存时间 / 顺序设置”。左上速度上限也会随设置保存。动作按钮会先保存当前设置再播放。

**空格 / 暂停保持**：取消动作队列，保持当前位置；再次播放从当前位置重新开始。
**Esc / 全部卸力**：关闭六只扭矩，使用前托稳机械臂。
退出窗口保持本程序控制过的关节，不自动回到初始位置。

ID5 重新安装后，仅保留更新后的 Middle 原始位置 `[383,683,641,649,688,112]`。其他姿态数值与旧采样已清空，但保留名称，方便在界面或 `record_poses_cli.py` 中重新录制。挥手动作的顺序、时长保留，缺少姿态时不能播放。

## 实现原理

- **位置换算**：沿用六个关节的端点，`展开位置 = 起点 + 比例 × 跨度`；下发原始位置时取 `% 1024`。保留原控制器的范围、反馈跳变、反向和停滞检查。
- **连续运动**：读取起点，使用 `q(t) = q起点 + (3s²−2s³) × (q终点−q起点)`，其中 `s=t/T`。六关节共享进度，逐步更新目标，起止速度平缓；不设置每个微小中间点都必须精确到位的关卡。
- **时间与速度**：各关节的命令变化速度随位移不同。若请求时间超过速度上限的能力，按最大位移计算最短时长并在界面提示延长；反馈滞后也会延长，实际时长不承诺精确到毫秒。每段最终稳定到位后才进入下一段。
- **通信与闭环**：复用上次基于 LeRobot 的 SCS 大端通信适配；PID 在舵机内部执行，本程序不修改 PID。异常时停止后续动作，保持可控制的关节；确认反向或停滞的关节卸力。

文件：`control_fk.py` 是入口和界面；`motion.py` 管理时间插值、动作和串口线程；`arm_backend.py` 提取上次的通信及单关节控制；`action_store.py` 校验、保存姿态；`actions.json` 存放六个比例和动作时序。

本程序是关节轨迹控制，不计算避障路径。首次播放录制动作时观察连杆路径；0～1 合法只代表单关节范围。跨反馈边界的实物行为仍以舵机反馈为准，离线模拟不构成实机验证。
