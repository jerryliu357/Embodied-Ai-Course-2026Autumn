# 双舵机控制课堂练习报告

本实验使用两只 SCS215 舵机，通过 Python 的 pyserial 库收发串口指令，自行组装协议数据包，不调用 lerobot 库。

## 1. 设置编号：set_id.py

单独连接需要改号的舵机，先关闭扭矩、解锁 EEPROM，再向 ID 寄存器 `0x05` 写入 `2`，将编号从 1 改为 2。随后通过新 ID 重新锁定 EEPROM，并读回编号确认。另一只保留 ID=1，接到同一条总线上后即可分别控制。

## 2. 设置范围：set_range.py

读取两只舵机的当前位置作为各自起点，按位置数值 0～1023 对应约 300° 换算角度跨度。ID=1 设置为从 403 到 710，约 90°；ID=2 设置为从 989 到 836，约 45°。第二只接近位置上限，因此采用反向范围。程序解锁 EEPROM，将最小、最大位置写入 `0x09`、`0x0B`，重新锁定并读回验证，最后将起点和终点保存到 `servo_config.json`。

## 3. 比例控制：control_servos.py

在代码顶部设置两个 0～1 的数字，分别控制两只舵机。程序读取保存的范围，按以下公式计算目标位置：

`目标位置 = round(起点 + 输入比例 × (终点 - 起点))`

例如两个输入均为 0.5 时，分别对应相对起点约 45°、22.5°。程序使用 `SYNC WRITE` 指令在同一个数据包中下发两个目标，读取实际位置检查是否到位，结束后关闭扭矩。
