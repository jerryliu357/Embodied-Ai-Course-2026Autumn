# 基于语音交互与主动视觉的机械臂寻球抓取系统

## 1. 想在 Agent 上完成什么功能

我们计划构建一个能够理解语音指令、主动寻找目标并完成三维定位与抓取的机械臂 Agent，初期以小球为抓取对象。主要功能包括：

- **语音交互**：理解“找到小球并拿起来”等自然语言指令，通过工具调用执行任务，并使用电脑音响播报结果。
- **主动观察**：目标不在当前视野内时，改变机械臂和腕部相机的观察姿态，在设定的搜索范围和时间内寻找目标。
- **物品抓取与举起**：估计小球的三维位置，控制夹爪接近、抓取并举起小球，检查抓取结果。
- **失败恢复**：在夹爪移动或抓取过程中，若出现小球被人为移动、暂时不可见、超出可达范围或抓取失败等情况，系统将重新观察、定位并调整动作；达到重试上限后，说明当前情况，并给出**自然、有趣的语音回应**，例如“球找不到了，你给我捡回来，我再试试”。
- **有趣的拓展动作**：完成上述功能后，计划探索**举球摇摆**、**庆祝**或**抛球**等拓展动作。

## 2. 为什么这些功能有趣或有用

**语音交互功能**能够使我们直接通过语音指挥机械臂；**主动观察功能**扩大了系统获取环境信息的范围，有助于提高后续任务的成功率；**失败恢复功能**使机械臂能够应对目标位置变化，提高交互过程的连续性。

例如，用户在机械臂准备抓取时突然移走小球，系统需要发现变化、调整行动，并在无法继续时向用户解释。自然语言反馈和适当的幽默回应也能增强现场互动的趣味性。

## 3. 计划如何实现

系统复用前期作业中的语音与视觉 Agent、工具调用、相机与手眼标定、机械臂正逆运动学和视觉伺服程序，形成以下流程：

**语音指令 → 主动搜索 → 三维定位 → 接近与抓取 → 结果检查 → 成功展示或重新尝试**

语音 Agent 负责理解任务、调用功能和生成反馈；视觉模块可以检测小球，结合不同视角的观测、相机标定和机械臂位姿估计目标的三维位置；控制模块根据目标位置规划接近、夹取和抬升动作，并在运动过程中更新视觉观测。

对于主动搜索功能，我们计划先采用若干预设观察姿态，能够尽可能覆盖机械臂周围的可观测范围。在抓取过程中，当发现目标因人为干预发生移动或离开视野时，中止原抓取动作并重新定位。在抓空后，同样会重新观察并尝试。任务流程设置搜索与重试上限，并将执行状态返回给 Agent，以生成对应的语音反馈，并在抓取成功后调用拓展动作。

## 4. Demo Day 准备展示什么

1. **语音寻球与抓取**：用户发出指令，机械臂识别并定位小球，完成抓取和举起，播报任务结果。
2. **主动搜索**：将小球放在初始视野之外、机械臂可达的位置，展示换视角寻找目标并完成抓取的过程。
3. **干扰后的恢复与回应**：在抓取前移动小球，展示重新定位和重试；将球移走或放到无法抓取的位置，展示系统结束尝试并通过语音说明情况。若进展顺利进一步展示抓取后的举球摇摆、庆祝或抛球动作。
